# Brasserie Belli — redesign-demo

Statisk demo af en moderne forside til Brasserie Belli, Frederiksgade 54, Aarhus C.

Alle billeder er restaurantens egne, hentet fra belli.dk. Menukort og priser stammer fra de aktuelle kort paa belli.dk.
Booking peger paa restaurantens eksisterende flow hos bord-booking.dk — der er ingen backend i dette projekt.

Kortdata: (c) OpenStreetMap-bidragydere.
